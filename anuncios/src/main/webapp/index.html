🏡 Anúncios Imobiliários

Em /agentes é possível:

  • Criar agentes novos
  • Listar todos os agentes existentes
  • Procurar agentes por ID
  • Apagar agentes por ID

Em /imoveis é possível:

  • Criar imoveis novos
  • Listar todos os imoveis existentes
  • Procurar imoveis por ID
  • Apagar imoveis por ID
  • Listar todos os imoveis geridos por um certo agente AINDA NAO ESTA FEITO

Em /clientes é possível:

  • Criar clientes novos
  • Listar todos os clientes existentes
  • Procurar clientes por ID
  • Apagar clientes por ID

Em /propostas é possível:

  • Criar propostas novas
  • Listar todas os propostas existentes
  • Procurar propostas por ID
  • Apagar propostas por ID
  • Listar todas as propostas criadas por um certo cliente AINDA NAO ESTA FEITO

Endpoints disponíveis:

http://localhost:8080/agentes

http://localhost:8080/imoveis

http://localhost:8080/clientes

http://localhost:8080/propostas
